Pengaturan Simpan Otomatis ke Google Drive

Masukkan PIN pengampu untuk membuka pengaturan koneksi Google Apps Script ke Folder Drive siswa:

Cara Mengaktifkan Simpan Otomatis File .MP4 ke Folder Drive (1 Menit):
1. Buka script.google.com menggunakan akun Google pemilik folder Drive.
2. Klik + Proyek Baru, hapus isinya, lalu klik tombol "Salin Kode Apps Script" di bawah dan tempel.
3. Klik Terapkan (Deploy) > Deployment baru > Aplikasi Web.
4. Pilih Jalankan sebagai: Saya (Me) dan Yang memiliki akses: Siapa saja (Anyone), lalu klik Terapkan.
5. Tempelkan URL Aplikasi Web (https://script.google.com/macros/s/.../exec) di kolom berikut:
